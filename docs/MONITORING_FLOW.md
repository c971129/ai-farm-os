# 田间监测业务逻辑

## 数据流

设备 → 厂家 API → 后台采集 → 原始记录入库 → 当前指标筛选 → 地块监测 → 业务页面引用。

传感器是数据来源，地块是业务对象，监测指标是业务输入。读数与历史曲线统一放在“田间监测”，不在设备、厂家页面重复整套数据面板。各页面引用同一份已采集数据，页面刷新不直接调用厂家。

## 页面分工

| 板块 | 显示内容 | 业务作用 |
|---|---|---|
| 首页 | 地块地址、空气温湿度与三项土壤指标摘要、数据时效 | 快速了解农情，进入田间监测 |
| 田间监测 | 气象全部指标、土壤三指标、设备/指标/时段选择、曲线和导出 | 完整的农情数据工作区；三个角色均可查看 |
| 看田地图 / 数字孪生 | 实际地块名称和地址、监测入口 | 地块档案与空间入口；真实边界未取得前不套用仿真地图坐标 |
| 水肥 | 土壤温度、湿度、EC | 研判依据；不以三项读数自动生成灌溉量或肥料剂量 |
| 田间设备 / 设备与传感网 | 设备编号、所属地块、连接状态、监测项数量、最后采集时间 | 排查通信、掉线、过期数据，进入监测详情 |
| 厂家接入中心 | 数据同步状态、采集频率、历史补数频率、接入设备/指标数量 | 接口连接与运维；不承载农情曲线 |

## 当前地块与指标

2000亩试验田：中国新疆维吾尔自治区克拉玛依市克拉玛依区白云一路与蓝天二路交叉口。地址由用户确认，系统直接展示；内部维护资料来源，界面不展示截图或接入实现说明。

土壤设备 `864317086512400` 仅呈现：

| 业务指标 | 当前厂家字段 | 单位 |
|---|---|---|
| 土壤温度 | AiMitrwd | ℃ |
| 土壤湿度 | AiMitrsd | % |
| 土壤 EC | AiMitrEC | μS/cm |

旧温湿度字段的零值是历史属性数据，不增加监测项数量、不参加摘要、不出现在当前指标下拉框。原始记录保留便于追溯。当前字段缺失时显示“等待采集”，不会用旧字段替补。

气象站 `864317086515478` 提供温度、湿度、风速、风向、气压和雨量。气象记录不与 App 天气预报卡混用；每项读数使用设备自己的采集时间。

## 与现有仿真业务的边界

实际读数带实际地块名称和地址；不会覆盖克拉玛依试验田、阿克苏等现有仿真农场数据。“田间监测”不使用仿真农场切换器。水肥、作业和地图中的仿真内容仍明确标注，不能因为采集已接通就认为生产处方、真实边界或设备控制已接通。

后续生产闭环应在实际地块下登记土壤类型、传感器深度、田间持水量、根层、天气、计量与校准，再将合格观测送入相应研判。当前范围完成监测和业务引用，未新增真实控制动作。
