# 左侧导航图标统一设计

## 目标

为农户/场长、农技专家和监管人员三种视角的左侧功能菜单提供统一、可辨识的图标系统。图标必须准确对应功能，不能再使用 Unicode 字符或通用回退符号冒充功能含义。

## 范围

- 仅调整左侧导航的图标渲染和视觉状态。
- 保留现有菜单分组、文字、页面 ID、角色切换、点击行为和权限边界。
- 覆盖三种角色实际可见的全部导航项。
- 不改动页面内容、业务 API、真实设备只读接入或模拟写入门禁。

## 实现设计

新增一个本地导航图标模块，由页面 ID 返回内联 SVG。模块只包含菜单使用的图标，不引入网络图标库或构建依赖。`app.js` 的菜单构建逻辑调用该模块，替换目前的 Unicode 字符映射和 `▣` 回退。

每个图标采用 24×24 视口、无填充、1.8px 描边、圆角端点和圆角连接。相同页面 ID 在三种角色中始终使用同一个图标；同一 ID 的不同文字只反映角色语境，不改变图标语义。

图标容器采用统一的圆角方块：普通态为低对比品牌色底，悬停态提高可见度，当前页面使用更深的品牌色与轻微强调。深色主题复用相同的语义和状态层级。侧栏收起、平板横向导航和手机窄屏继续沿用现有尺寸断点，SVG 随容器缩放。

## 验收

1. 农户/场长、农技专家和监管人员的每个菜单项均显示 SVG 图标。
2. 现有 Unicode 菜单图标和 `▣` 静默回退不再用于正常菜单。
3. 图标与菜单文字可见、对齐，当前项、悬停项、深色主题和收起侧栏保持清晰。
4. 现有导航跳转和角色切换可用。
5. 前端合同检查覆盖“所有导航 ID 均有专属图标”。
6. 在当前本地服务中逐角色人工验证，并检查桌面、平板和手机断点。

## 失败处理

图标模块缺少某个导航 ID 时，页面保持可用并显示通用应用图标；测试会明确报出缺失 ID，阻止遗漏进入交付。图标仅用于展示，不改变按钮标签、标题或无障碍文本。
